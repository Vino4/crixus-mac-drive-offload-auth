# Privacy policy

Effective November 21, 2026.

Crixus Mac Drive Offload is an owner-operated local tool for transferring files between the owner's Mac and Google Drive.

It requests Google's `drive.file` permission. The owner selects the files or folders available to the app using Google's picker. It reads account identity, authorized file metadata and file contents only as needed to verify the account and perform requested listings, uploads, downloads and checksum checks. It may create, modify or delete authorized files when the owner requests those operations.

OAuth credentials remain in the owner's encrypted local configuration. The encryption key is stored in macOS Keychain. Authorized transfers go directly between the local tool and Google's services. The app does not sell data, use it for advertising, or train AI models on it. No app-operated central service collects Drive contents. Local filenames, metadata and operational logs may be retained by the owner for transfer verification.

The owner controls local copies and Google Drive retention. Access can be revoked through Google Account's third-party connections settings; local configuration and logs can be removed separately. Revoking this app does not revoke the separate SR4710 app.

Google API data use follows the Google API Services User Data Policy, including its Limited Use requirements. For questions, contact the owner through this repository's issues without posting private files or credentials.
